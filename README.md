# NAVEROSHOP — site statique

Projet sans compilation (un seul fichier HTML, sans Vite, React ni dépendances).

- Fichier principal : index.html
- Configuration (prix, numéro WhatsApp, quantité max) : bloc CONFIG dans le script de index.html
- Commande de compilation : aucune
- Déploiement Vercel : Framework Preset « Other », Build Command vide, Output Directory vide
